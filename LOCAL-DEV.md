# Локальный просмотр

Статические файлы можно открыть напрямую, но **форма обратного звонка** и `POST /api/callback` работают только через сервер:

```bash
py -3 server/app.py
```

Откройте http://127.0.0.1:8080/

Пересборка HTML после правок:

```bash
py -3 tools/build_site.py
```

Настройка доставки заявок: скопируйте `.env.example` в `.env` и укажите `CALLBACK_WEBHOOK_URL` или параметры SMTP.

Публикация на домене: **[DEPLOY.md](DEPLOY.md)** (nginx + waitress, без записи заявок в открытые файлы).
